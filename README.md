# Paperclip — Windows 剪贴板便签

一个常驻屏幕右侧的剪贴板历史小工具。Electron 构建，**纯本地运行，不联网**。

## 它能做什么

- 自动记住你复制过的**文字和图片**，随时点一下就能再用
- 按 `Alt + Shift + V` 随时唤起 / 隐藏面板，不用时屏幕上**完全不显示**，不会误触
- 点记录**不抢走光标**，点完回原处直接 `Ctrl + V` 就行
- 按「全部 / 文字 / 图片」分类查看
- 常用内容可**置顶**（邮箱、签名、地址等），清空时不会被挤掉
- 多选几条**一键合并复制**，自动带上 1. 2. 3. 编号
- 字号小 / 中 / 大可调，支持开机启动
- 面板位置可上下拖动；一段时间无操作会自动隐藏
- 记录上限 200 条（图片 80 张），旧的自动清理

## 使用方法

1. 启动后屏幕上不会出现任何东西，它在后台安静记录
2. 像平时一样 `Ctrl + C` 复制，内容自动进入历史
3. 按 `Alt + Shift + V` 唤出面板，查看 / 选用记录
4. 点击某条记录即复制，回到目标处 `Ctrl + V` 粘贴
5. 再按一次 `Alt + Shift + V`（或点面板左侧书脊、底部「最小化」）即可隐藏

## 开发与打包

```bash
npm install
npm start        # 本地运行
npm run dist     # 打包为免安装 exe（electron-builder portable）
```

环境要求：Node.js 18+，Windows 10/11。

## 技术要点

- Electron 33：无边框透明窗口 + 置顶 + 不抢焦点（`focusable: false`）
- 剪贴板 700ms 轮询，SHA1 去重，并忽略自身写入的回环
- 全局快捷键 `globalShortcut`（`Alt+Shift+V`），退出时自动注销
- 窗口隐藏 = 整窗 `hide()`，唤醒时从屏幕右缘滑出

## 数据与隐私

- 历史与设置保存在 `%APPDATA%/Paperclip/paperclip.json`，图片存在同级 `images` 目录
- 无任何网络请求；卸载时删掉该目录即可彻底清空
